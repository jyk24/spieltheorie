Nim-Summe & Sprague-Grundy

Nim ist vollständig gelöst. Bilde das bitweise XOR aller Reihengrößen – die Nim-Summe. Ist sie nicht 0, hat der Spieler am Zug eine Gewinnstrategie: Es gibt immer einen Zug, der die Nim-Summe auf 0 setzt. Ist sie 0, verliert der Ziehende bei perfektem Gegenspiel.

Start 3-5-7 → 011 XOR 101 XOR 111 = 001 = 1 (≠ 0)
⇒ Der anziehende Spieler (du) kann immer gewinnen.

{% if final.result == 'win' %} ✓ Gegen den {{ 'Meister' if final.difficulty == 'meister' else 'Anfänger' }} gewonnen – wer am Zug die Nim-Summe auf 0 hält, gewinnt zwangsläufig. {% else %} ✗ Ein einziger Zug, der die Nim-Summe ungleich 0 ließ, reichte dem Meister zum Sieg. Versuch, jeden Gegner mit Nim-Summe 0 zurückzulassen. {% endif %}

Das Konzept: Nim begründete die kombinatorische Spieltheorie. Der Satz von Sprague-Grundy zeigt, dass jedes unparteiische Spiel (beide Spieler haben dieselben Züge, kein Zufall, vollständige Information) einem Nim-Haufen entspricht. Aus Nim folgt also die Lösung einer ganzen Spielklasse.
